03 / How I work

How I approach
a project

I’ve worked as a solo developer, a consultant and a lead. The amount of planning changes with the project, but I like staying close to the code and the people making the game.

Open to senior, lead & consulting opportunities
01

Prototyping

I work with design to decide what we need to test first. At The Polygon Loft, I built playable prototypes in under a week per build and led three programmers through to a vertical slice.

02

Leading a small team

At Gamkat, I handled technical direction, estimates, code reviews and mentoring for up to five programmers. I break features into tasks and talk through the trade-offs with the team.

03

Optimisation

I spend time profiling on the target hardware before changing things. My work has included draw calls, geometry, rendering and code bottlenecks on mobile and console.

04

AI tools and workflows

At Trick Studios, I’ve been building AI-assisted tools for a custom game engine using Claude Code and Codex. That includes specialised agents, multi-agent workflows and reusable agent skills.

Some of that work focuses on profiling and debugging tools; some is about making development tasks easier to repeat and review. I also use coding agents in my own projects.

AI-assisted engineering & developer workflows

04 / A little background

A bit about me

I started in software development at Redmond Software in 2013, working with Java, databases, and REST and SOAP APIs. I studied game programming and design at Escuela Da Vinci and moved into games.

Since then, I’ve worked with studios in Argentina and the UK, from early prototypes to released games. Between 2020 and 2023, I also taught Unity, code structure and design patterns.
